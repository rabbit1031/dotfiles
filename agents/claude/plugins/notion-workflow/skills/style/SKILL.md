# Notion 作業メモ 文体ガイド

Notion に作業メモを書き込む（`notion-create-pages` / `notion-update-page`）ときの本文の文体を、本人が書くドキュメントに合わせるための指針。定型見出し（`## 目的` 等）の構造は**維持**し、各セクションの**本文の文体だけ**を以下に寄せる。

## 基本方針

- 体言止め・名詞句中心。敬体（ですます）を避け、常体で簡潔に
- 前置き・接続詞の多用を避け、要点から書く
- コマンド・設定・差分が主役。作業はコードブロックで示し、直前に短いラベルを添える
- 実際の出力・diff・パスは省略せず貼る（再現性のため）
- 箇条書きは浅く。3 段以上のネストや過剰な太字を避ける

## 文体の例

体言止めに寄せる:

- ✅ 読み取り系 Notion MCP コマンドを permissions.allow に追加
- ❌ 読み取り系の Notion MCP コマンドを permissions.allow に追加します

冗長な説明を削る:

- ✅ デフォルトで MCP ツール呼び出しに毎回承認を求める
- ❌ Claude Code はデフォルトの状態では、MCP ツールの呼び出しに対して毎回ユーザーに承認を求める仕様になっています

コマンドにはラベルを添える:

```
読み取り系コマンドを allow で確認
$ jq '.permissions.allow' ~/.claude/settings.json
```

## 維持するもの（文体を寄せても崩さない）

- kickoff の見出し: `## 目的` / `## 背景・制約` / `## 成果物` / `## 完了条件` / `## タスク分解`
- wrapup の見出し: `## 決定事項` / `## 成果` / `## 残課題`
- タスク分解のチェックボックス記法（`- [ ]`）
